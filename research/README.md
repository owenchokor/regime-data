## 최종 결론 (52wh_final_report.pdf)
1. 실적(EPS) 상향 종목 우선, 52주 고점 정확 도달·거래대금 급증·단기 과열 종목은 후순위.
2. 딜 조건에 가격이 묶인 종목(주식교환·합병·자산매각·청산)과 거래정지 이력 종목은 공시로 확인 후 제외 — 데이터 필터 밖의 정성 영역.
3. 밸류에이션·적자여부·업종·거시 레짐은 판별력 없음. 단, 적자·과열 종목은 평균은 높고 중앙값은 낮은 복권형(하위25% 확률 28~35% vs 실적상향 종목 22%) → 5개로 좁힐 때는 회피.
4. 기계 규칙만으로는 부족(표본외 IC 0.06, A안에서 KOSPI 확정 우위엔 IC 0.15~0.2 필요) → 정성평가가 이 격차를 메워야 함.
5. 운용 절차: 규칙순위 1차 정렬 → 딜/정지 공시 제외 → 정성 채점 → 5개 매수(부족하면 현금) → 채점 커밋해 forward IC 측정.

## 해석
- 52WH는 알파 원천이 아니라 후보 생성기. 초과수익은 재선별 IC가 만들어야 함.
- 52WH 신호 가치는 월말 직후 며칠에 집중 — 월말·월초 수급 효과 혼입 가능성은 확인 필요(미해결).
- 스펙트럼의 IC는 가정값. 실제 IC는 forward 채점으로만 측정 가능.

## 대기 중
- DART 재수집 완료 후: 이벤트 목록(주요사항보고서)으로 딜 종목 자동 플래그, 재무 주요계정으로 자본잠식·연속적자·부채비율 정량 필터 사전등록 → WF 판정.
- 애널리스트 리포트(목표주가·추정치) 수집 — EPS 상향이 가장 강한 신호였고 컨센서스가 가장 큰 공백이었음. `docs/HANDOFF.md` 참고.
