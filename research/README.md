## 기준값
- 3차 기준형(WF): CAGR 17.7%, Sharpe 0.91, MDD −18.1%, CVaR5 −7.8%.
- 3차 통과기준: ① Sharpe ≥ 기준형 − 0.05 ② MDD 또는 CVaR5 3%p 이상 개선 ③ 이웃값에서 ① 유지.
- 8차 A안, k=5, 전 기간 KOSPI 대비 연 초과수익 중앙값: IC 0 −8.7%p / 0.1 +4.9%p / 0.2 +23.3%p / 0.3 +42.8%p. MDD는 IC 0.2에서도 약 −50% (2026 급락 포함).
- 익일 체결 20개 전체(기계적): 전 기간 CAGR 7.0%, Sharpe 0.33, MDD −55.7% — KOSPI 대비 −5.4%p.

## 해석
- 52WH는 알파 원천이 아니라 후보 생성기. 초과수익은 재선별 IC가 만들어야 함.
- 52WH 신호 가치는 월말 직후 며칠에 집중 — 월말·월초 수급 효과 혼입 가능성은 확인 필요.
- 스펙트럼의 IC는 '실현수익 순위와의 상관'으로 모델링한 가정값. 실제 IC는 forward 채점으로만 측정 가능.
