# regime-data

국내주식 랠리 신호 시스템 — 시장 국면 판정 모듈

## 구조
- `collect/` : KRX·FRED 데이터 수집 스크립트
- `regime/`  : 국면 판정 로직 (강세/박스권/약세)
- `results/` : 백테스트 결과 (자동 생성)
- `.github/workflows/` : 일별 자동 수집 Actions

## 국면 정의 (오닐 기반)
- **강세**: 개별주 상승이 두드러진 국면 — 지수 추세 + 시장폭(breadth) + 분배일 + 매크로
- **박스권**: 강세·약세 조건 미충족
- **약세**: 지수 하락 추세 + 시장폭 축소

## 데이터 소스
- 가격/수급: pykrx (KRX 정보데이터시스템)
- 매크로: FRED (DEXKOUS, DGS10 등)
