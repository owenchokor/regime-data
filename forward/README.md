# Forward 모의운용

`forward.yml`이 평일 KST 19:00 실행: KRX 지수·배당수익률·전종목 패널 증분 → `run_forward.py` → `forward/` 커밋.
확인 채널: **`forward/STATUS.md`** (GitHub 모바일 가능). 텔레그램 알림은 Phase 3.

## 사전등록 운용안 (2026-09-26 확정)
| 트랙 | 정의 | 상태 |
|---|---|---|
| ① 기준형 | 52WH 상위 20 동일가중 × KOSPI PxMA10 게이트, 월간 교체 | 가동 |
| ② +스톱10% | ① + 종목 트레일링 스톱 10% (트리거 다음날 종가 청산) | 가동 |
| ③v2 정성 재선별 (A안) | 월말 저녁 후보 20개 절대점수(0~100) 채점 → 익일 종가에 70점 이상 점수순 최대 5개 동일가중 매수, 0개면 현금 | 인프라 구축 중 |

③v2 규칙 (2026-09-26 변경, 사용자 승인 — 기존 '보유 하한 k=5' 폐기, 소급 적용 없음):
- 채점 대상 20개(①의 후보). 종목별 0~100 절대 척도(루브릭 `phase3/rubric.md` 고정), 70점 이상만 점수순 최대 5개. 0개면 전액 현금.
- DART 딜·재무위험 플래그 종목은 채점 전 기계적 배제 (필터 사전등록 전까지 `pending`).
- 원점수 전부 기록 → 6~12개월 뒤 점수 구간별 적중률로 기준점 재보정.
- 월말 거래일(XKRX 캘린더) 실행분이 `decisions/{월}.csv`(채점 입력) 생성·커밋 후 텔레그램 게시.
- 알려진 트레이드오프: 현금 비중 증가 시 폭락 회피 대신 급반등장 누락 가능 → forward로 판정.
- 게이트 OFF 월(2026-09-26 사용자 결정): 토론·채점은 그대로 하고 매수는 안 함(현금). 규칙상 선정은 `shadow`로 기록해 예측력 평가에 포함.
- 청산 규칙 변형 병행 기록(`forward/exit_sim.py`, 원금 1억, 익일 종가 체결): ③HOLD / ③T10(종목 트레일링 10%) / ③R200(KOSPI 200일선 이탈 전량 청산) / ③T10+R200. 파라미터는 3차 연구값. ① 기준 과거 비교는 `research/exit_rules/`.
- 채점은 매수 전 커밋 (사후 편향 차단). 1개월·3개월 수익 기준 IC를 모두 기록.
- 핵심 지표: 월별 순위 IC(채점 vs 실현수익)의 누적 평균±표준오차, 선택군 − 후보 20개 수익 차이.
- 판정 소요 추정(2σ, 후보 20개): IC 0.3 약 3개월 / 0.2 약 6개월 / 0.1 약 21개월.
- B안(20개 선매수 후 거르기)은 8차 진단에서 모든 IC·k에서 A안보다 열위 → 미채택.
